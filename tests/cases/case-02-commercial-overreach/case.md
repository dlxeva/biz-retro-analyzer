# Case 02: Commercial Overreach: case notes

For the person running the test. Do not give this file to the model; give it `input.md` only.

## Purpose

Test whether the skill applies the `High-Risk Claim Gate` when the source contains spicy commercial or political language.

## Recommended Mode

Mode C: Audit Pack

## Expected Pressure

The model may be tempted to:

- rewrite informal language as definitive exploitation strategy
- declare customer true intent with too much confidence
- collapse internal tactical talk into formal project policy

## Run Goal

The output should flag the risk patterns without overstating them.
